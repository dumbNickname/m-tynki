## 2. Findings & actions

### Critical

**C1. Verify the "firma tynkarska" drop (131 → 6 clicks).**
In July this was the best keyword (pos ~4) and was served by
`/uslugi/firma-tynkarska-wroclaw/`. On 2026-07-31 (commit 9ade8d0) that page was removed
and meta-refresh-redirected to `/tynki-ze-szlichta-pod-malowanie/` — a page about
szlichta/tynki maszynowe, not about "the company". The intent-matching page for
"firma tynkarska" is the **homepage** (title/H1 already say "firma tynkarska").
- GSC → Performance → query `firma tynkarska` → Pages tab; compare periods before/after 31 Jul.
- Fix regardless: redirect `/uslugi/firma-tynkarska-wroclaw` → `/` (one line in
  `scripts/generate-redirects.mjs`), and `/uslugi` → `/`.

**C2. Redirect stubs send mixed signals.**
Stubs combine `meta refresh 0` + `canonical` + `noindex`. Google treats a 0-second
meta refresh as a permanent redirect, but `noindex` on the source tells it to drop the
URL — which can discard signals rather than consolidate them. Remove the `noindex` line.
Longer term: GitHub Pages can't do HTTP 301 or headers. Putting Cloudflare (free) in front
or moving to Cloudflare Pages/Netlify gives real 301s (`_redirects`) + security headers.

### High

**H1. Define one target per keyword cluster and align titles.**
- Homepage → `firma tynkarska`, `tynki wrocław`, `tynkarz wrocław`, `tynkowanie wrocław`.
  Body currently contains "tynki maszynowe" 0×, "tynki wrocław" 0×.

  domów i mieszkań" and linking to the flagship with anchor "tynki maszynowe".

  Title is fine. H1 "Tynki maszynowe ze szlichtą pod malowanie" — add "Wrocław".

**H2. "Elewacje" — decide (owner question).**

with facades (probably via GBP category or old WordPress content). If M-TYNK does
elewacje/tynki zewnętrzne/docieplenia → dedicated page `/elewacje-wroclaw` (separate intent,
no cannibalization). If not → ignore and check GBP categories don't claim it.

**H3. Freshness — the site has not changed content-wise since 2023.**

problem, podłoże, what was done). Each new post in a different town/osiedle builds
long-tail local relevance ("tynki Oława", "tynki Długołęka" …) honestly.

**H4. Google Business Profile + reviews (off-site, biggest lever for "… wrocław").**

count 10). Map-pack results sit above organic for every "wrocław" query in the table.
Ask every client for a review; target 2–3/month; reply to all. Add GBP photos weekly.
